## OpenCodeList CLI

[OpenCodeList CLI](https://github.com/openpotato/opencodelist.cli) ist ein Kommandozeilenwerkzeug zum Importieren und Exportieren von OpenCodeList-Daten zwischen dem nativen OpenCodeList-Format und verschiedenen unterstützten externen Formaten.

Die CLI stellt zwei Befehle bereit:

* **export**: Exportiert Daten aus einem Codelisten-Dokument (im OpenCodeList-Format) in ein unterstütztes Zielformat (CSV, SSV oder Excel).
* **import**: Importiert Codelisten-Daten aus einem unterstützten Quellformat (CSV oder SSV) in ein Codelisten-Dokument (im OpenCodeList-Format).
